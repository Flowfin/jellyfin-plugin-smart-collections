# Every member of the server's own BaseItemKind enumeration, by value and name, in
# declaration order. Read out of the assembly each supported line resolves rather
# than out of its source, because a package asks the server for the VALUE and no
# member of that enumeration declares one explicitly: the value is the member's
# position, so a line that later inserts a member anywhere but at the end moves
# every value after it while every name is still present.
#
# Taken on 2026-09-01 over the two pins Jellyfin.Plugin.SmartCollections.Engine.csproj
# declares, with a file-based program that reads the constants out of the metadata:
#
#   for v in 10.11.11 12.0.0-rc4; do
#     tf=net9.0; case $v in 12.*) tf=net10.0;; esac
#     dotnet run --file kinds.cs ~/.nuget/packages/jellyfin.data/$v/lib/$tf/Jellyfin.Data.dll > out-$v.txt
#   done
#   diff out-10.11.11.txt out-12.0.0-rc4.txt && echo "identical in order and value"
#   identical in order and value
#

# compiled against, on each target framework, so a move on either line reds the
